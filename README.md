# صادق چراغ

این پوشه کپی مستقل بازطراحی فروشگاه است و پایگاه SQLite خودش را دارد. برای پیش‌نمایش کنار پروژهٔ اصلی، پس از نصب وابستگی‌ها در PowerShell این نسخه را روی پورت ۴۱۸۱ اجرا کنید:

```powershell
$env:SADEGH_PORT = '4181'
npm.cmd start
```

پیش‌نمایش بازطراحی: http://127.0.0.1:4181/

این پروژه ظاهر و کاتالوگ اولیه را از فرانت React ارائه‌شده می‌گیرد. داده‌های فعلی برای آزمایش‌اند. پنل مدیریت تغییرات و سفارش‌ها را در SQLite ذخیره می‌کند.

## اجرا روی ویندوز

پوشهٔ پروژه را باز کنید و با Node.js نسخهٔ ۲۴ یا بالاتر این دستورها را بزنید.

```powershell
npm.cmd ci
npm.cmd start
```

- فروشگاه http://127.0.0.1:4180/
- محصولات http://127.0.0.1:4180/products
- پیگیری سفارش http://127.0.0.1:4180/track
- پنل مدیریت http://127.0.0.1:4180/admin

اگر دسترسی به npm ندارید و نسخه‌های پکیج‌ها یکسان‌اند، می‌توانید `node_modules` را از پروژهٔ اصلی `sadeghcheragh` کنار `package.json` این پروژه کپی کنید و مستقیم `npm.cmd start` را اجرا کنید.

پرداخت بعد از هماهنگی با فروشنده انجام می‌شود. برای آزمایش سفارش می‌توانید از نام و نشانی ساختگی و موبایل 09120000000 استفاده کنید. این نسخه روی آدرس محلی اجرا می‌شود و پنل برای همان سیستم در دسترس است. فایل `sadegh-cheragh.sqlite` را برای نگهداری داده‌ها حفظ کنید.

برای توسعه، فقط `npm.cmd run dev` را اجرا کنید و آدرس Vite را باز کنید. فرانت و API روی همان آدرس اجرا می‌شوند و نیازی به سرور جدا روی پورت ۴۱۸۰ نیست. برای آزمون خودکار، ابتدا سرور را با `$env:SADEGH_DB=':memory:'` و سپس `npm.cmd run api` بالا بیاورید و در ترمینال دوم `node verify.mjs` را بزنید. آزمون روی پایگاه موقت دادهٔ نمونه می‌سازد.
